# Уведомления APC 204

[Українська — основна версія](README.md)

Скрипт следит за тревогами APC, сохраняет их историю и сообщает о новых тревогах голосом и выбранной мелодией. Работает на странице `http://172.23.255.204/desktop/#deviceGroups`.

**[Установить готовый скрипт](https://raw.githubusercontent.com/Ovolsan/Notifications-APC-204/main/Notifications%20APC%20204.user.js)**

## Установка

1. Установите расширение [Tampermonkey](https://www.tampermonkey.net/) в Microsoft Edge, Google Chrome или Firefox.
2. Перейдите по ссылке **«Установить готовый скрипт»** выше и нажмите **«Установить»** в Tampermonkey. Если вместо установки открылся текст, создайте новый скрипт в Tampermonkey, полностью замените его содержимое этим текстом и сохраните.
3. Отключите предыдущую копию скрипта APC 204, если она у вас есть. Одновременно должна работать одна копия.
4. Откройте страницу APC и обновите её. Внизу слева появится таймер.
5. Если Tampermonkey запросит разрешение на доступ к `raw.githubusercontent.com`, разрешите его: оттуда загружаются переводы.

## Интерфейс

Нажмите таймер, чтобы открыть панель. Кнопки внизу переключают **Историю**, **Фильтры** и **Настройки**. Кнопка **«Закрыть»** сворачивает панель. Над нижними кнопками находится переключатель дневного и ночного режима.

- **История** показывает сохранённые тревоги. Новые записи появляются внизу. Нажмите **«Скрыть»** у тревоги и укажите постоянную часть её описания, чтобы добавить фильтр для этого Label.
- **Фильтры** содержат исключения из уведомлений. Новые фильтры добавляются внизу; ненужные можно удалить.
- **Настройки** позволяют выбрать язык, загрузить мелодии и открыть инструкции для браузера.

История и фильтры открываются в более широкой панели, настройки — в компактной. Панель ограничена видимой областью страницы, а длинные списки и инструкции прокручиваются внутри неё. На узком экране таблицу можно прокручивать по горизонтали. Кнопки внизу остаются доступными. В настройках оставлены небольшие отступы по краям и между блоками.

Таймер перезагружает страницу через **5 минут** бездействия. Работа мышью или клавиатурой ставит его на паузу; через 10 секунд бездействия отсчёт продолжается. После ухода с вкладки к оставшемуся времени добавляется до 2 минут, но общий остаток не превышает 5 минут. Открытая панель приостанавливает отсчёт, пока вкладка видима. На скрытой вкладке мониторинг продолжается.

## Звук и работа в фоне

Откройте **Настройки**, выберите файл мелодии для дневного и/или ночного режима и нажмите **«Тест»**. Перед мелодией звучит слово «Батареї». Клик по странице останавливает играющую мелодию. Используйте аудиофайлы размером до 2 МБ.

Включите нужный режим кнопкой **«День» / «Ночь»**. В ночном режиме используется AFK-мелодия. Если мелодия не выбрана, остаётся голосовое уведомление, если браузер разрешает его запуск.

Если таймер показывает **«Звук не запустился»**, разрешите воспроизведение звука для сайта. Если показывает **«Нет мелодии»**, выберите аудиофайл. После изменения разрешений обновите страницу APC и нажмите **«Тест»** ещё раз. Проверьте также, что вкладка и браузер не заглушены.

В настройках скрипта есть отдельные кнопки **«Разрешения для Edge»**, **«Разрешения для Firefox»** и **«Разрешения для Chrome»**. Они раскрывают инструкции; адреса можно скопировать кнопкой **«Копировать»** и вставить в адресную строку браузера.

| Браузер | Звук | Работа вкладки в фоне |
| --- | --- | --- |
| **Microsoft Edge** | Откройте `edge://settings/content/mediaAutoplay` и разрешите автовоспроизведение. Если доступен список сайтов, добавьте `http://172.23.255.204`. | Откройте `edge://settings/system/managePerformance` → **«Всегда сохранять эти сайты активными»** / **«Завжди зберігати ці сайти активними»** и добавьте адрес APC. В старых версиях пункт называется **«Никогда не переводить эти сайты в спящий режим»**. |
| **Google Chrome** | Разрешите звук для APC в `chrome://settings/content/sound`. При блокировке воспроизведения нажмите **«Тест»** в настройках скрипта. | Откройте `chrome://settings/performance` → **«Всегда сохранять эти сайты активными»** и добавьте адрес APC. |
| **Firefox** | Откройте `about:preferences#privacy` → **«Разрешения»** → **«Автовоспроизведение»** → **«Параметры»**. Для APC выберите **«Разрешить аудио и видео»**. | Не выгружайте вкладку APC вручную на `about:unloads`. Если используете расширение для усыпления вкладок, добавьте APC в его исключения. |

В настройках скрипта есть кнопка копирования адреса APC — `http://172.23.255.204` — для добавления в список активных сайтов.

Для мониторинга оставляйте браузер и вкладку APC открытыми, а компьютер — включённым. Сон компьютера или принудительная выгрузка вкладки останавливают скрипт. Названия пунктов настроек браузера могут отличаться в зависимости от его версии и языка.

## Языки и сохранение настроек

По умолчанию выбран **Українська**. Также доступен **Русский**.
Переводы находятся в отдельных файлах [languages/uk.json](languages/uk.json) и [languages/ru.json](languages/ru.json). Скрипт загружает выбранный перевод из этого репозитория при запуске и при первом переключении на другой язык. Если GitHub недоступен, используется сохранённый перевод или встроенный резерв — мониторинг продолжает работать.
Для исправления перевода достаточно изменить соответствующий JSON в папке `languages`, сохранив названия ключей. После обновления файлов перезагрузите страницу APC; GitHub может показать изменения с небольшой задержкой.
