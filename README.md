# APC 204 Alarm Reloader & Manager — 2.25

Готовый скрипт: `APC-204-Alarm-Reloader.user.js`.

## Установка в Microsoft Edge

1. Откройте в Tampermonkey **первый скрипт — APC 204** и полностью замените его содержимое содержимым файла `APC-204-Alarm-Reloader.user.js`. Сохраните. Не оставляйте две включённые копии этого скрипта.
2. Нажмите таймер внизу слева → **⚙️ Настройки** → **Разрешения для Edge**. Все инструкции открываются этой кнопкой. Для Firefox и Chrome рядом есть свои кнопки.
3. В Edge откройте **Настройки → Система и производительность → Производительность → Всегда сохранять эти сайты активными**. В старых версиях пункт называется **Никогда не переводить эти сайты в спящий режим**. Добавьте `http://172.23.255.204`. Адрес нужного раздела — `edge://settings/system/managePerformance`; рядом с ним в инструкции есть кнопка **Копировать**.
4. Если таймер пишет **«Звук не запустился»**, откройте `edge://settings/content/mediaAutoplay` и разрешите автовоспроизведение мультимедиа. Проверьте также, что звук не выключен для сайта или Edge в микшере Windows. Даже работающая фоновая вкладка не снимает ограничение автовоспроизведения.
5. Перезагрузите страницу APC. Состояние **Фон: поддержка включена** отображается в настройках и подсказке таймера. Кнопкой «Тест» в выбранном звуковом режиме проверьте и голос, и мелодию. После изменения разрешений Edge снова перезагрузите страницу.
6. Для проверки на вашем APC оставьте вкладку в фоне минимум на 10–15 минут при текущем 5-минутном таймере. Проверьте обновление страницы и поступление ожидаемых тревог. Во время проверки закройте DevTools: открытые инструменты разработчика сами могут предотвращать сон вкладки.

Список исключений Edge защищает сайт от сна и оптимизаций энергосбережения. Его нельзя настроить из обычного userscript. Инструкция Microsoft: https://support.microsoft.com/en-us/edge/learn-about-performance-features-in-microsoft-edge

## Изменения

- Добавлены два локальных WebRTC-соединения с открытым каналом данных между ними. Это поддерживает фоновые таймеры Chromium. Используется `iceServers: []`, без внешних STUN/TURN-серверов, микрофона, камеры и постоянного воспроизведения звука. При разрыве соединение пересоздаётся через 15 секунд.
- Добавлен индикатор состояния. «Поддержка включена» означает, что канал открыт; это не проверка настроек сна Edge. Если отображается «защита недоступна» или долго остаётся «повтор подключения», обязательно проверьте исключение сайта в настройках Edge.
- Автоматические клики при чтении тревог больше не считаются действиями оператора и не ставят мониторинг на паузу.
- После переключения с вкладки мониторинг возобновляется. Последовательные события `blur` и `visibilitychange` добавляют время один раз.
- Меню приостанавливает мониторинг и таймер, пока вкладка видима. Оставленное открытым меню не мешает проверкам в скрытой вкладке.
- Уже обработанные тревоги сохраняются даже при прерывании чтения оператором.
- Отсутствие системных уведомлений на HTTP не прерывает работу скрипта. Разрешение запрашивается только там, где API доступен, после настоящего клика пользователя.
- Мелодия запускается сразу после окончания TTS или через 4 секунды, если TTS завис. Ошибка TTS тоже запускает мелодию.
- Ошибка `Audio.play()` отображается в индикаторе. Незвучавшая тревога сохраняется в localStorage до успешного запуска мелодии и переживает перезагрузку; после блокировки автовоспроизведения звук повторяется при настоящем клике пользователя.
- Тестовые кнопки звука используют ту же цепочку, что и новая тревога.
- Таймер и раскрывающаяся панель расположены внизу слева, по образцу приложенного скрипта sd.bitech. Клик по таймеру открывает панель; нижние кнопки переключают историю, фильтры и настройки. Переключатель дня/ночи расположен над кнопками. Полноэкранное меню заменено компактной панелью с прокруткой.
- В настройках инструкции скрыты под кнопками для Edge, Firefox и Chrome. Адреса настроек, включая раздел «Завжди зберігати ці сайти активними», и адрес APC можно копировать кнопкой. На HTTP используется резервный способ копирования.
- Ошибку звука видно в компактном таймере; подробное состояние звука и фоновой поддержки находится в настройках.

История, фильтры, выбранные звуки и язык используют прежние ключи localStorage. Адрес и содержимое озвучки APC сохранены. Интервал перезагрузки возвращён к 5 минутам: `TIMER_MAX_SEC = 5 * 60`.

## Языковые файлы

Загрузка ru.json и uk.json из репозитория технически возможна. По вашему решению она отложена до создания репозитория; в версии 2.25 переводы остаются внутри скрипта. При добавлении внешней загрузки следует сохранить встроенные переводы как резерв, чтобы недоступность репозитория не мешала мониторингу.

Второй приложенный скрипт не содержит отдельного механизма защиты от сна. Его логика таймеров и обработчиков активности совпадает с первым. Отличаются имя, адрес/маршрут, HTTP/HTTPS и текст озвучки. Поэтому различие поведения нельзя однозначно объяснить только их кодом.

Обоснование поддержки таймеров: https://developer.chrome.com/blog/timer-throttling-in-chrome-88

## Проверка

В изолированном Microsoft Edge 154.0.4258.53 выполнены 15 успешных функциональных проверок без ошибок JavaScript. Проверены реальные локальные RTC-каналы, переподключение, отсутствие дубликатов соединений, освобождение ресурсов, обработка тревог и служебных кликов, настоящие действия пользователя, сохранение при прерывании, недоступность API и перезагрузка по таймеру. Для звука проверены нормальная последовательность «голос → мелодия», зависший TTS, ошибка TTS, отказ в автовоспроизведении и восстановление звука после перезагрузки и настоящего клика. Скрытое состояние страницы и ошибки звука моделировались для проверки логики скрипта.

Файл проверки: `test-background.cjs`. Он использует локальную тестовую страницу и отдельный профиль браузера, не обращается к устройству APC. Для запуска в этой рабочей среде: `node test-background.cjs`.

Дополнительно в `test-ui.cjs` проверены компактный таймер, открытие и закрытие панели, инструкции для трёх браузеров, копируемые адреса, украинский язык, резервное копирование на HTTP и размещение на узком экране. Для запуска: `node test-ui.cjs`.

Длительный фоновый запуск на реальном APC и фактический переход Edge в сон здесь не проверялись. Закрытая/принудительно выгруженная вкладка или сон Windows останавливают JavaScript; скрипт не может гарантировать работу в этих состояниях.

Ограничение автовоспроизведения: https://developer.chrome.com/blog/autoplay/ . Разрешение мультимедиа в Edge управляется браузером: https://learn.microsoft.com/en-us/deployedge/microsoft-edge-policies/autoplayallowed .

Инструкции для Firefox основаны на https://support.mozilla.org/en-US/kb/block-autoplay и https://support.mozilla.org/en-US/kb/unload-inactive-tabs-save-system-memory-firefox . Инструкция для Chrome об активных сайтах: https://support.google.com/chrome/answer/12929150 . Разрешение воспроизведения звука в Chrome не отменяет все условия его политики автовоспроизведения.
